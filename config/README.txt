  HOW TO EDIT WEBSITE CONTENT
  ────────────────────────────
  1. Open any of the text files below in Notepad (or any
     text editor — double-click the file to open it).

  2. Change the text AFTER the  =  sign to whatever you want.

  3. Save the file.

  4. Refresh your website browser tab.
     That's it — your changes appear instantly!

  ⚠  IMPORTANT RULE
  ─────────────────
  Only change the text AFTER the  =  sign.
  Never change or delete the word BEFORE the  =  sign.

  CORRECT:   name = My New Room Name
  WRONG:     My New Room Name = name
  WRONG:     name  My New Room Name
